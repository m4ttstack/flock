# Paddock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS app that mirrors the whole herdr session live (1:1 terminal content) and rearranges workspaces/tabs/panes via drag and drop, converging on herdr ground truth in both directions.

**Architecture:** Three planes over herdr's NDJSON socket API: an event-sourced `HerdrStore` actor (subscribe-buffer-snapshot bootstrap, reducers, re-snapshot backstop); a `ContentPlane` that spawns one `herdr terminal session observe` child per attached pane and feeds SwiftTerm views; a `MutationEngine` that compiles gestures into plans of primitive ops with optimistic apply, typed-error rollback, and an inverse-op undo journal. The drag layer is a custom in-window DragGesture state machine with overlay ghosts and dropzones.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, macOS 15+, SwiftTerm (SPM), XcodeGen, XCTest + XCUITest.

**Spec:** `docs/superpowers/specs/2026-09-10-paddock-design.md` (read it first; every task argues from it)

## Global Constraints

- macOS 15+, Swift 6 strict concurrency. Xcode project is generated: edit `project.yml`, run `xcodegen`, never hand-edit `Paddock.xcodeproj`.
- herdr protocol floor: startup `ping` must report `protocol >= 22` (pinned by spike 7: herdr 0.9.0 stable ships protocol 22, live-confirmed on the dev machine 2026-09-10).
- herdr connection contract (spike 2 + source dive): one request per connection; never write any byte on a subscription or pending-wait connection. Success payloads unwrap through their type-specific wrapper key (`.result.move_result` etc., spike 3).
- Live pane frames come ONLY from `herdr terminal session observe` child processes. Never connect to `herdr-client.sock`.
- Every herdr request sends explicit ids. Never rely on the focused-pane fallback (it belongs to the human).
- `layout.apply` is never called on live panes anywhere in the codebase (it destroys PTYs).
- ALL test and spike herdr traffic targets named scratch sessions (`herdr --session paddock-<purpose>-$$`), never the default session. Fixtures are captured only from scratch sessions (real-session content must never enter the repo).
- No em dashes or en dashes in any code, comment, doc, commit message, or UI copy. Use plain hyphens, parens, or "...".
- Comments follow clean-code rules: only constraints the code cannot show. No narration, no process references.
- Every interactive SwiftUI element gets `.accessibilityIdentifier("paddock.<area>.<role>.<id>")`; the e2e suite depends on them.
- Commit at the end of every task, and after any spike that produced findings.
- No UI implementation code before Task 14's design-canvas sign-off. Tasks 9-13 are UI-free plumbing.
- Agent status colors mirror herdr's header semantics (source: herdr `src/client/shell.rs` `status_color`), pinned to Tokyo Night: working `#E0AF68`, blocked `#F7768E`, done `#7DCFFF`, idle `#9ECE6A`, unknown `#565F89` (light chrome: Tokyo Night Day `#8C6C3E`/`#F52A65`/`#118C74`/`#587539`/`#8990B3`). Zoom badge is mauve `#BB9AF7`, never a status color.
- Hands-on checkpoints (spec "Hands-on checkpoints"): the build STOPS after Tasks 16, 18b, 22, 26, and 28b. At each stop, build and launch paddock for Matt to try against his live session, collect feedback, fold it in before the next task. These are gates like Task 14, not FYIs.

```bash
#!/usr/bin/env bash
# Scratch herdr servers only: never touches the default session.
set -euo pipefail
cmd="$1"; name="paddock-${2:?session name}"
sock="$HOME/.config/herdr/sessions/$name/herdr.sock"
case "$cmd" in
  start)
    herdr --session "$name" server >/dev/null 2>&1 &
    for _ in $(seq 1 50); do [ -S "$sock" ] && break; sleep 0.1; done
    [ -S "$sock" ] || { echo "server did not bind $sock" >&2; exit 1; }
    echo "$sock" ;;
  stop)
    HERDR_SOCKET_PATH="$sock" herdr server stop || true
    rm -rf "$HOME/.config/herdr/sessions/$name" ;;
esac
```

- [ ] **Step 1: Build a minimal DispatchIO unix-socket NDJSON client**

```swift
// Throwaway probe. Core shape mirrors what Task 11 will build for real.
import Foundation

final class LineSocket {
    private let fd: Int32
    private let channel: DispatchIO
    private var buffer = Data()
    var onLine: ((Data) -> Void)?

    init(path: String) throws {
        fd = socket(AF_UNIX, SOCK_STREAM, 0)
        var addr = sockaddr_un(); addr.sun_family = sa_family_t(AF_UNIX)
        withUnsafeMutableBytes(of: &addr.sun_path) { raw in
            path.utf8CString.withUnsafeBytes { raw.copyBytes(from: $0) }
        }
        let size = socklen_t(MemoryLayout<sockaddr_un>.size)
        let r = withUnsafePointer(to: &addr) {
            $0.withMemoryRebound(to: sockaddr.self, capacity: 1) { connect(fd, $0, size) }
        }
        guard r == 0 else { throw POSIXError(.init(rawValue: errno)!) }
        channel = DispatchIO(type: .stream, fileDescriptor: fd, queue: .main) { _ in }
        channel.setLimit(lowWater: 1)
        channel.read(offset: 0, length: .max, queue: .main) { [weak self] done, data, err in
            guard let self, let data else { return }
            self.buffer.append(contentsOf: data)
            while let nl = self.buffer.firstIndex(of: 0x0A) {
                self.onLine?(self.buffer[self.buffer.startIndex..<nl])
                self.buffer.removeSubrange(self.buffer.startIndex...nl)
            }
        }
    }
    func send(_ line: String) {
        (line + "\n").data(using: .utf8)!.withUnsafeBytes {
            channel.write(offset: 0, data: DispatchData(bytes: $0), queue: .main) { _, _, _ in }
        }
    }
}
```

```swift
final class NullTerminalDelegate: TerminalDelegate {
    func send(source: Terminal, data: ArraySlice<UInt8>) {}

// Spawn: herdr terminal session observe <pane> --cols 80 --rows 24
// Parse each NDJSON line, base64-decode "bytes", feed the terminal.
let term = Terminal(delegate: NullTerminalDelegate(), options: TerminalOptions(cols: 80, rows: 24))
func feed(frame: [String: Any]) {
    guard let b64 = frame["bytes"] as? String, let data = Data(base64Encoded: b64) else { return }

}

}
```
