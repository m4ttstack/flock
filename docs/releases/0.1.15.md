## New

- A `flock` shell command. Settings > Command Line installs it in your PATH (`~/.local/bin`), and `flock help` lists its commands.
- `flock release` hides Flock so herdr sizes its panes for your other clients, like Moshi on a phone. It works over ssh. Clicking Flock takes the panes back.
- `flock attach` releases, then opens herdr in the same terminal. Arguments after `attach` go to herdr.

## Changed

- The rt menu leads each row with rt's command name (`cd`, `nav`, `glitter`, `run`, `runner`), with the description smaller beside it, like the command palette. It is a little narrower too.
