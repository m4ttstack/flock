## New

- A `flock://open` link from Board opens a merge request's worktree in a focused tab of the repo's pinned workspace, or of Board's MRs workspace, and runs its command once the shell is ready. It needs mattstack 2.30.0 or later.

## Fixes

- Overview and Arrange show chat names again, and Flock no longer shows a "no name for you here" chat error at launch.
- Opening a pane's chat menu no longer hangs on macOS 15 when the pane is outside a git repository.
- A `flock://open` link reuses Flock's window, and reopens it if it was closed, instead of opening a second window that froze the app.
