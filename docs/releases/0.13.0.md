## Changes

- Flock now installs and updates herdr from the mattstack build of herdr, a signed and notarized build that carries Flock's changes. It no longer patches herdr itself.
- With no herdr on the Mac, the missing-herdr screen installs it for you.
- Settings, the update banner and the title-bar pill all show the same herdr status, and every install still asks first.
- After an update, Flock offers to hand your running panes over to the new herdr without closing them.
- The old patch, restore and revert options are gone, along with the backup copy of herdr they kept.

**Full Changelog**: https://github.com/m4ttstack/flock/compare/v0.12.2...v0.13.0
