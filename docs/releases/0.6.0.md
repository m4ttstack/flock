## New

- ⌘K opens the command palette over a pane you opened from Overview. It offers what applies there: rt, chat, launchers, rename, close, the mouse toggle, Back to Overview and Open Next Card.

## Changed

- The palette lists only the commands that work on the view you are in.
- Close Pane is the last pane row in the palette, so ⌘K then Return never closes a pane.

## Fixes

- A moved pane shows in its new tab at once. It no longer lingers in the old tab or appears in both.
- A pane moved into another workspace keeps its terminal instead of attaching again.
- ⌘K in a pane opened from Overview no longer clears the screen and leaves a full-screen program in fragments.
- A Claude pane running a mix of background tasks (agents, MCP tasks, workflows) shows as working instead of idle.
