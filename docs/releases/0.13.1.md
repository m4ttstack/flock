## Changes

- When installing herdr fails, the missing-herdr screen says why in a clear card. If only its Claude integration failed, the card gives the command to finish it, with a Copy button, and stays until you continue.
- Settings says "Checking for a newer build…" until the herdr build list has loaded, instead of saying it couldn't read it.
- Confirming a herdr server restart only ever restarts the server you were asked about, even if you switch sessions while the question is open.
