## New

- File paths and links in a pane are live. Hover one and it underlines; click it to open it. A relative path is read from the pane's folder.
- Rest on a link for half a second and a chip comes up above it: Open and Reveal for a file, Open and Copy for an address.
- Right-click a link for Open File, Reveal in Finder and Copy Path, or Open Link and Copy Link. Option-right-click still shows the full pane menu, with the link's items on top.
- Links in any scheme an app on your Mac handles work, not only web addresses. The first time you open one, Flock asks, and you can choose to always open that kind. Settings > General lists the kinds you trust.

## Changed

- Only the path is a link in a line like `cd ~/src/app && git pull`, not the command after it.
- Opening an app or an executable file from a pane shows it in Finder instead of running it.

## Fixes

- The underline sits under the link when an emoji or a wide character comes before it on the line.
