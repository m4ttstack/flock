## New

- Move a pinned workspace to the top bar from its menu, or drag it there. Top-bar workspaces sit in the title bar as buttons, coloured by status, and open in an overlay over your tabs that remembers its size per workspace.
- A pinned workspace with no tabs open now shows its name, folder and a launcher. Press Return for a shell, or pick rt cd, Claude or Codex to start there.
- Pinning a workspace asks which folder it should reopen in.
- Closing a tab or pane that is running an agent asks first. Tick "Don't warn me next time" to stop asking, or change it later in Settings > General > Closing.
- Settings is now split into tabs.

## Changed

- The launcher on an empty prompt is a compact frosted bar. It sits just below the prompt, and a ⌘ key lights the item it launches.
- rt cd from the launcher opens every repo, not just the current one.
- A ⌘ key never launches into a half-typed line or into a pane you cannot see.
- Keys that act on panes, tabs and workspaces stay off in Overview and Arrange, where the Workspaces view is hidden.

## Fixes

- Launching Claude, Codex or rt cd from an empty pinned workspace now waits for the new shell to be ready, instead of doing nothing.
- The new pane's own launcher no longer flashes up while one of those launches starts.
- The launcher comes back after a line is typed and erased, and stays away after Ctrl-L over typed text.
- Closing or moving a workspace's active tab now selects another tab.
- Dragging in the sidebar behaves correctly around pinned workspaces.
