## New

- Mouse support works with every herdr from 0.9.1 to 0.9.5. Flock downloads the build for your herdr version when you click Install, checks it against a fingerprint it already knows, and shows progress while it downloads.
- Flock tells you when a newer herdr is out: a small pill in the title bar, and a note in Settings > herdr.
- Update herdr from Settings without closing your panes. Flock runs the update, puts mouse support back if it was on, and asks once to restart.
- A clear warning appears before an update that would turn mouse support off because Flock has no build for that herdr yet.

## Fixes

- A Claude tab keeps its name after herdr is updated, instead of falling back to "shell" until the agent next does something.
- rt runs and runners stay open across a herdr update.
- Clicking Install no longer asks twice when the banner and Settings are both open.
- Settings shows mouse support correctly after herdr changes outside Flock.
