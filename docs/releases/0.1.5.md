## What's new

**rt opens in a modal.** When `rt` is on your PATH, each pane's title row gets an rt button. It opens a menu to browse files (`rt nav`), check git status (`rt glitter`), run a script (`rt run`) or start a runner (`rt runner`). Each one opens in a modal over the tabs, sized for the job instead of taking a split, starting in the pane's folder. Close the modal and a run keeps going: the button counts it, and its menu brings it back. A pane's runner shows as a pink half of the button, one click away. "cd here" in rt nav moves the pane to that folder, or opens a split there if the pane is busy. A queue or preset picked in rt run becomes the pane's runner, with an rt new enough to have `rt runner --seed-file`. Pick Small, Medium or Large from the modal's title row; flock remembers it.

**Rearrange mode steps aside after a move.** A drag that changes the layout now turns rearrange mode off. Settings has an "After a move" choice to keep it on, as before.

## Fixes

- Return confirms the close prompts for panes, tabs and groups, and the confirm button stays blue as the prompt goes away.
- A notification jumps straight to its tab, instead of briefly showing the workspace's last tab first.
- The dock keeps its notification cards across a relaunch.
- Moving a window from a Retina display to a standard one no longer shrinks a pane's text into its top-left corner.
- The title bar takes its own clicks again; the tab strip had been catching them.
- Ctrl+Return reaches the terminal instead of opening the context menu.
