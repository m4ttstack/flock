## New

- When herdr's server is still running an older build than Flock's mouse patch, Flock says so and offers Restart herdr. It hands your panes to a new server on the current build, so shells and agents keep running, then restarts Flock to reconnect them.

## Fixes

- An agent that resumes as a pane attaches waits briefly for Flock's light or dark theme, so Claude Code's Auto theme no longer starts dark in a light Flock. The theme also carries across a herdr restart. Both need the updated herdr mouse patch, which Settings and a banner offer.
