## What's new

**Move focus between panes from the keyboard.** ⌘⌥ + an arrow focuses the pane on that side, the same keys Ghostty uses for its splits. Typing follows the focus, just as if you had clicked the pane.

## Changed

- Move Pane is now ⌘⌃ + arrow and Swap Pane is ⌘⌃⇧ + arrow, to make room for focus. All three live in the View menu.
