## New

- Profiles: keep separate setups side by side, each with its own settings and its own herdr server. Switch between them from the new Profile menu, and add or edit them in Settings > Profiles.
- Choose which herdr server a profile drives: the default one, another running server, a new server Flock starts for you, or a socket path of your own. Flock switches in place, without a restart.
- Settings lists your herdr servers with whether each is running, and can stop or delete the ones you no longer need. The default server, the one you're on, and one another Flock is using are never offered.
- A server with no workspaces now shows a start screen instead of an empty window: pick a harness or press Return for a shell, and choose the folder it opens in. The sidebar gets a New Workspace row too.
- The "herdr isn't running" screen names the server it's waiting for.

## Fixes

- When chat signs a new agent in automatically, its chat button catches up on its own instead of waiting for a click.
- Clicking a link in a pane resolves it against that pane's folder, even after panes have moved around.
